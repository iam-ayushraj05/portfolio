# 🌌 Ayush Raj's Developer Portfolio

A modern, highly interactive personal portfolio showcasing full-stack development skills with a dynamic space-themed aesthetic.

The website features a fully interactive **AI Chat Widget**, smooth GSAP scroll animations, a 3D particle network background, and a responsive glassmorphism layout to highlight projects, achievements, and technical expertise.

Live Preview -> [text](https://portfolio-sigma-beryl-zfspl9kych.vercel.app/)
---

## ✨ Features

• Interactive **AI Chat Widget** with quick replies and typing indicators
• Dynamic **Three.js Particle Network** background
• Smooth scroll animations powered by **GSAP**
• Beautiful **Glassmorphism** UI design
• Live integrated **Visitor Counter**
• Fully functional contact form via **EmailJS**
• Dark/Light theme toggling
• Fully responsive mobile-first architecture
• Clean, premium typography with Inter and Playfair Display

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3** (Custom Variables & Grid/Flexbox)
- **JavaScript** (Vanilla ES6+)
- **Three.js** (For 3D background rendering)
- **GSAP & ScrollTrigger** (For scroll animations)
- **EmailJS** (For form handling)
- **FontAwesome** (For iconography)

---

## 📂 Sections

The portfolio includes the following sections:

- **Hero** – Introduction, dynamic typewriter text, and floating tech icons
- **Services** – Detailed breakdown of professional offerings
- **Arsenal** – Core technology stack and programming languages
- **Timeline** – Professional experience and educational journey
- **Achievements** – Certifications, hackathons, and awards
- **Projects** – Showcase of featured web applications and tools
- **Contact** – Direct email form, social links, and live chat
